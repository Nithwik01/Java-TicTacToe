# 🎮 Java Tic-Tac-Toe Game

A two-player Tic-Tac-Toe game developed using Java and Object-Oriented Programming (OOP).

## 🚀 Features

- Two-player gameplay (X and O)
- 3×3 game board
- Automatic player switching
- Input validation
- Prevention of duplicate moves
- Horizontal, vertical and diagonal win detection
- Draw detection

## 🛠️ Technologies Used

- Java
- Visual Studio Code
- 2D Arrays
- Scanner
- Object-Oriented Programming

## ▶️ How to Run

1. Clone this repository:

```bash
git clone https://github.com/Nithwik01/Java-TicTacToe.git
```

2. Open the project folder in VS Code.

3. Compile the Java files:

```bash
javac *.java
```

4. Run the game:

```bash
java Main
```
